# Android Application Development – Fall 2026 Assignment

## Overview

This repository contains a Java object-oriented programming assignment focused on employee inheritance, earnings calculations, and salary-based tax calculations.

The project currently provides only the initial class structure. Business logic and user-interface components will be added in later development steps.

## Package

All Java classes use the `com.example` package and are located under `src/main/java/com/example`.

## Required Classes

- `Employee`
- `HourlyEmployee`
- `SalariedEmployee`
- `CommissionEmployee`
- `BasePlusCommissionEmployee`
- `EmployeeTest`

## Planned Functionality

- Model a hierarchy of employee types using inheritance.
- Calculate earnings according to each employee type.
- Calculate taxes based on salary or earnings.
- Exercise and verify the employee classes through `EmployeeTest`.

No business logic or Android user interface has been implemented yet.
